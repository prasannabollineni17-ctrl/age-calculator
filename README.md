# Age & Date Calculator

A clean, responsive web application for calculating exact age breakdowns, total calendar days lived, upcoming birthday countdowns, and age projections on future dates.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fprasannabollineni17-ctrl%2Fage-calculator)

---

## 🌟 Features

- **Precise Age Calculation**: Exact breakdown into **Years, Months, and Days**, accurately handling leap years and varying month lengths.
- **Total Days Lived**: Exact count of calendar days lived, plus weeks, hours, and minutes.
- **Age on Future Date**: Flexible date selector with quick presets (`+1 Year`, `+5 Years`, `+10 Years`, `Age 60`).
- **Next Birthday Countdown**: Days remaining until next birthday and the weekday it falls on.
- **Accurate Zodiac Sign**: Western Tropical Zodiac sign with dates and symbols.
- **Day Born On**: Exact day of the week of your birth date.
- **Clean Human Design**: Soft light orange and warm cream palette.
- **One-Click Copy**: Copy a clean text breakdown summary to clipboard.
- **Fully Responsive**: Mobile, tablet, and desktop optimized.

## 🚀 Deploying on Vercel

### Option 1: One-Click Deploy Button
Click the button above or visit:
[https://vercel.com/new/clone?repository-url=https://github.com/prasannabollineni17-ctrl/age-calculator](https://vercel.com/new/clone?repository-url=https://github.com/prasannabollineni17-ctrl/age-calculator)

### Option 2: Import via Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and choose `age-calculator`.
3. Click **Import**.
4. Leave all build settings as default (zero configuration needed for static HTML/CSS/JS).
5. Click **Deploy**!
